# StoryBridge Launcher

Переносимый лаунчер GTA V Legacy и Enhanced для Windows.

## Скачать

**[Скачать StoryBridge Launcher v0.1.0 для Windows](https://github.com/kychalox007/storybridge-releases/releases/download/v0.1.0/StoryBridgeLauncher-windows-v0.1.0.zip)**

[Все релизы](https://github.com/kychalox007/storybridge-releases/releases)

## Как открыть

1. Скачай ZIP и полностью распакуй его в обычную папку.
2. Открой `StoryBridgeLauncher.exe`, оставив `.exe.config` рядом.
3. Нажми «Найти игру» или укажи `PlayGTAV.exe` через «Выбрать папку».
4. Выбери версию игры и свой клиент — Steam или Rockstar Games Launcher.

Нужны Windows 10/11 x64, .NET Framework 4.8 и установленная GTA V с официальными клиентами.

## Что умеет

- Ищет Legacy и Enhanced в библиотеках Steam и известных папках Rockstar.
- Передаёт запуск официальному клиенту.
- Поддерживает параметр сюжетного офлайн-режима `-scofflineonly`.
- Показывает диагностику установки.

Это первая проверочная сборка. Лаунчер не заменяет авторизацию и проверку лицензии Rockstar. Офлайн-режим может потребовать предварительный вход и периодическое подключение к интернету. Полный запуск GTA V на компьютере разработки пока не проверен.

Приложение не связано с Rockstar Games, Take-Two Interactive или Valve.
